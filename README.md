\# AI Study Assistant



A study helper built with Python, Streamlit and the Gemini API.



\## Features

\- Chat with an AI tutor that remembers the conversation

\- Generate quizzes and get them graded

\- Make flashcards on any topic

\- Upload notes and get a summary



\## How to run

1\. Install packages: `pip install -r requirements.txt`

2\. Get a free API key from aistudio.google.com/apikey

3\. Set it: `set GEMINI\_API\_KEY=your\_key` (Windows)

4\. Run: `streamlit run app.py`
